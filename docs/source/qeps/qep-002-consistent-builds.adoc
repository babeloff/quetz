== Requirements

Any Makefile and associated scripts should be migrated into the main pixi.toml if possible,
in a sub-project if necessary,
and any scripts used in any pixi.toml should be in the pixi-scripts/ directory.
If any pixi-scripts are bash or bat files,
they should be converted into python or nushell scripts.

== Implementation plan

* Replace the documentation Makefile and batch launcher with root Pixi tasks for building and cleaning documentation.
* Keep executable task helpers in `pixi-scripts/` and convert the CI and development shell helpers to Python.
* Update CI,
container commands,
source distribution contents,
tests,
and documentation to use the new tasks and paths.
* Preserve plugin failure aggregation,
container health checks,
and release artifact validation.
Verify these behaviors with isolated tests before exercising the Pixi tasks and documentation build.

== Implementation

The root `pixi.toml` provides the documentation build and cleanup tasks,
CI service and plugin tasks,
and example package download and upload tasks.
All task helpers live in `pixi-scripts/` as Python files.
The plugin manifests need no separate task subprojects.
The documentation Makefile and Windows batch launcher have been removed.

CI and the development Compose stack call the same Python helpers.
Source distributions include `pixi-scripts/*.py`.
The site navigation contains only navigation;
the obsolete embedded script has been removed.

See link:https://github.com/babeloff/quetz/blob/main/CONTRIBUTING.adoc#build-task-reference[the build task reference] for commands and their included implementation sources.
