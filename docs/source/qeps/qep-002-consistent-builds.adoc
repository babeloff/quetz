== Build conventions

Define build and development automation in the root `pixi.toml` wherever possible.
Use a subproject only when necessary.
Store every project-owned script invoked by a Pixi manifest in `pixi-scripts/`.
Use Python or Nushell for these scripts.

The root tasks replace the documentation Makefile and batch launcher.
CI,
container readiness,
example package transfers,
documentation,
and release assembly use the shared Python helpers.
Bundled plugin manifests need no separate task subprojects.
Source distributions include the helpers.

== Verification scope

Fourteen focused helper and release tests passed at the implementation baseline,
alongside lint,
type,
workflow,
documentation,
and packaging checks.
The maintained verification baseline records the full scope and results.
Service-helper tests use mocked Podman and PostgreSQL commands;
they do not establish a live container startup after the Python conversion.
