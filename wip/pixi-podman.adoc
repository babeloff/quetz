= Pixi and Podman migration

== Plan

Use `pixi.toml` and `pixi.lock` as the maintained environment definitions.
Replace package-manager subprocesses in plugin installation and solving with Pixi.
Give bundled plugins Pixi build manifests and keep their existing entry points.
Preserve the solver HTTP endpoint and explicit-spec response format.
Replace the current-repodata plugin's Conda indexer dependency with Rattler matching.
Keep latest builds,
dependency backfills,
featureless alternatives,
and legacy archive hashes.
Run system-language pre-commit-compatible hooks with `prek` so hook setup does not create installer-managed Python environments.
Build Python distributions without an isolated environment installer.
Replace image recipes and Compose paths with Containerfiles and Podman tooling.
Start CI service containers explicitly with Podman.
Update hosted documentation and release checks to use the same locked environments.
