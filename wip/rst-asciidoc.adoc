= reStructuredText to AsciiDoc migration

== Plan

Convert every maintained `.rst` source to `.adoc` while preserving document URLs,
examples,
admonitions,
tables,
and cross-references.
Replace Sphinx navigation directives with explicit AsciiDoc index links.
Preserve the generated authenticator and hook reference material through prose and tagged source includes.
Replace the Sphinx build with a native Asciidoctor site build,
including assets and navigation.
Update Pixi tasks,
Read the Docs,
CI,
Make wrappers,
and contributor instructions.

== Verification

Render all converted documents with warnings treated as errors.
Check local links,
anchors,
images,
and source includes.
Compare original code examples and external link targets with the rendered output.
Verify the Pixi lockfile and packaging still include the documentation sources.

All external link targets,
tables,
and admonitions were preserved.
Validation checked 295 local links,
images,

the Make wrapper,
